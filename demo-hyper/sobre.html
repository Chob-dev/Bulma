Sobre o Projeto

O HyperBook é uma aplicação front-end que simula uma livraria virtual com curadoria de títulos clássicos e contemporâneos. O objetivo deste projeto para a disciplina de Web II foi evoluir uma interface estática para um design system moderno, adotando boas práticas de UI/UX, componentização de estilos e arquitetura mobile-first.

Funcionalidades

  • Catálogo de Livros: Visualização em grid responsivo com paginação e destaques.
  • Autenticação: Telas de login e cadastro com validação HTML5.
  • Carrinho de Compras: Gerenciamento de itens, cálculo de subtotal e checkout com modal de confirmação.
  • Layout Mobile-First: Interface que se adapta a qualquer tamanho de tela, com navegação otimizada para smartphones.

Tecnologias e Ferramentas

  • HTML5: Estruturação semântica e acessibilidade.
  • Bulma CSS (v1.0.4): Framework CSS moderno baseado em Flexbox para desenvolvimento ágil e responsivo.
  • CSS3 Customizado: "Hacks" (como :target e :checked) para criar interatividade em modais e menus responsivos sem a dependência obrigatória de JavaScript.

Aprendizados e Desafios

A transição de Web I para Web II exigiu uma forte refatoração de código. O principal desafio foi migrar um layout de CSS puro e engessado para a estrutura do framework Bulma.

Foi necessário compreender a lógica de grids (colunas dinâmicas), utilitários de espaçamento (margin/padding) e resolver conflitos de responsividade em telas menores (como o ajuste da barra de promoções fixa e o menu sanduíche). Essa etapa consolidou conhecimentos essenciais sobre frameworks de mercado e manutenção de código front-end limpo.
