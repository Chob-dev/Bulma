Responsividade

O Bulma é um framework CSS baseado em Flexbox que oferece recursos nativos e intuitivos de responsividade utilizando sufixos em suas classes para diferentes tamanhos de tela.

Breakpoints

O Bulma utiliza os seguintes pontos de quebra padrão baseados na largura da tela:

Mobile: até 768px (padrão para smartphones)
Tablet: a partir de 769px (-tablet)
Desktop: a partir de 1024px (-desktop)
Widescreen: a partir de 1216px (-widescreen)
FullHD: a partir de 1408px (-fullhd)

Sistema de Colunas Flexível

Por padrão, como visto no exemplo acima, as colunas do Bulma empilham-se em telas de celular e lado a lado em tablets ou superiores.

- Para manter as colunas lado a lado também no mobile, adicione a classe modificadora is-mobile ao elemento .columns.

- Você pode definir larguras específicas por tamanho de tela usando sufixos (ex: is-half-desktop, is-one-third-tablet, is-6-tablet).

Sufixos de Classes Responsivas

Várias classes utilitárias aceitam sufixos de dispositivos para alterar o comportamento conforme a largura da viewport:

- Tamanho de texto: is-size-1-mobile, is-size-3-desktop, etc.

- Alinhamento e visibilidade: classes para ocultar ou exibir elementos em breakpoints específicos (como is-hidden-mobile ou is-block-desktop).

Recursos para mobile

Sistema de grid responsivo: As colunas empilham-se automaticamente em telas de celulares por padrão e podem ser ajustadas com sufixos como -mobile, -tablet e -desktop.

Classes de visibilidade: Permitem ocultar ou exibir elementos específicos dependendo do tamanho da tela (por exemplo, is-hidden-mobile ou is-block-mobile).

Modificadores de tamanho: O tamanho de textos e elementos pode mudar conforme o dispositivo usando sufixos como is-size-3-mobile.

Menu de navegação responsivo (-navbar): Inclui o botão "hambúrguer" (-navbar-burger) que gerencia o comportamento de abrir e fechar menus em telas pequenas (requer uma pequena lógica em JavaScript para alternar a classe is-active).
