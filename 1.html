Como usar?

arigato gozaimasu

  1. Via CDN

    2. Esta é a abordagem mais ágil para integrar o Bulma ao projeto. Consiste em adicionar o link fornecido por servidores de distribuição (como jsDelivr ou unpkg) diretamente na tag do documento HTML. É um método excelente para prototipagem rápida e projetos acadêmicos, pois dispensa o download de arquivos locais. No entanto, exige conexão ativa com a internet para que o layout seja renderizado corretamente.

  2. Download do arquivo CSS

    3. Este método envolve baixar o pacote oficial do framework, extrair o arquivo bulma.min.css e incluí-lo fisicamente no diretório do projeto. A principal vantagem desta abordagem é a total independência de conexão com a internet. O desenvolvimento e a apresentação podem ser realizados offline com a garantia de que a interface não sofrerá quebras de estilo.

  3. Pelo NPM ou Yarn

    4. É o padrão estabelecido pelo mercado para ambientes de desenvolvimento profissional. Utilizando o terminal, o Bulma é instalado como uma dependência direta do projeto. Esta é a prática recomendada ao desenvolver aplicações escaláveis ou ao integrar o framework com ecossistemas JavaScript modernos, tais como React, Vue.js ou Angular, permitindo um controle rigoroso das versões utilizadas.

  4. Sass

    5. O ecossistema do Bulma é integralmente desenvolvido utilizando Sass, um robusto pré-processador CSS. Ao optar por importar o código-fonte .scss em vez do CSS compilado, os desenvolvedores ganham controle absoluto sobre o design system. É possível sobrescrever variáveis globais (como a paleta de cores principal, tipografia e espaçamentos da grade) antes da compilação, resultando em uma interface altamente personalizada e única.
